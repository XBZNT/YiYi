# 易译 YiYiTranslator

一个免费的 Windows 文档 + 屏幕翻译小工具。**零依赖、零安装**：单个 exe（约 85KB），OCR 用 Windows 10/11 自带引擎（离线），翻译走必应/腾讯/有道等免费网页接口。

## 使用

双击 `YiYiTranslator.exe`，程序常驻在任务栏右下角托盘（橙色"译"字图标）。

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 屏幕翻译 | `Ctrl+Alt+S` | 按下后拖拽框选屏幕上的文字 → OCR 识别 → 弹窗显示译文（弹窗置顶，可一键复制） |
| 翻译剪贴板 | `Ctrl+Alt+V` | 复制文字后按此键，直接弹出翻译 |
| 文本翻译 | `Ctrl+Alt+T` | 打开输入窗口，输入后 Ctrl+Enter 翻译 |
| 文档翻译 | `Ctrl+Alt+D` | 打开文档翻译窗口，选文件或把文件拖进窗口 |

**以上快捷键都可以修改**：托盘右键 → 设置 → 快捷键，点击对应按钮后直接按下新组合键（需包含 Ctrl 或 Alt，按键支持字母/数字/F1-F12），点"保存"立即生效。设置时会自动检测组合键冲突和是否被其他程序占用。

托盘图标**右键**菜单里有：全部功能入口、目标语言/引擎设置、开机自动启动、退出。

## 文档翻译

- 支持：`txt` / `md` / `log` / `srt` / `docx` / `pdf`
- 输出：生成在原文件旁边，名字加 `.translated` 后缀，**不改动原文件**
  - `报告.docx` → `报告.translated.docx`（保留段落和样式，段内文字替换为译文）
  - `论文.pdf` → `论文.translated.txt`（PDF 走"整页渲染 + OCR"路线，扫描版也能翻；输出为分页文本）
  - `笔记.md` → `笔记.translated.md`（保留标题/列表/代码块/网址，只翻译正文行）
- 大文件逐段调用免费接口，速度约每秒几段，翻译一篇几十段的文档通常需要一两分钟

命令行方式（可写脚本批量）：

```
YiYiTranslator.exe --translate-doc "D:\docs\报告.docx" --to zh-CN
```

## 翻译引擎

默认按此顺序自动尝试，失败自动降级到下一个：

1. **必应**（推荐，国内直连，质量最好）
2. **腾讯交互翻译 transmart**
3. **有道**
4. 谷歌（国内网络通常无法访问，开着代理时会自动用上）
5. MyMemory（备用）

设置里还可以填自己申请的**百度翻译 / DeepL** 免费密钥（可选）。

## 屏幕识别（OCR）

使用 Windows 自带的离线 OCR，需要在系统里装有对应的语言包（你的系统已有 `zh-Hans-CN`）。
识别语言默认"自动"（中英各识别一次取质量高的），可在设置里固定。

如需增加语言：Windows 设置 → 时间和语言 → 语言 → 添加语言 → 勾选"文本识别"。

## 从源码构建

不需要安装 Visual Studio，Windows 自带的 .NET Framework 编译器即可：

```
build.bat          （生成 YiYiTranslator.exe）
```

源码在 `src\`，纯 C#（兼容系统内置编译器支持的 C# 5 语法），可用 VS Code 打开编辑。
运行 `test\TestHarness.exe` 可执行全量自测（OCR/各引擎/docx/md/pdf/设置/截屏）。

## 常见问题

- **弹"没有可用的 OCR 语言包"**：按上面方法添加语言包。
- **所有接口都失败**：检查网络；错误详情见 `%APPDATA%\YiYiTranslator\error.log`。
- **配置文件**：`%APPDATA%\YiYiTranslator\settings.json`（目标语言、引擎顺序、密钥等）。
- **热键没反应**：可能被其他软件占用（如显卡/输入法快捷键），到 设置 → 快捷键 换一组，或用托盘菜单触发同样功能。

## 已知限制

- PDF 输出为纯文本（不重建排版）；表格、双栏 PDF 的行序可能交错。
- docx 翻译后段内的加粗/颜色等局部格式会被合并（段落样式保留）。
- 屏幕翻译框选在多显示器不同缩放比例时，边缘可能有少量偏移。
